1. Installation & Quick Start

Download the latest Atomvs installer for Windows (.exe) or macOS (.dmg) from the Releases page, launch the app, and sign in via Settings → Account.

Open or Scaffold a Project

  • Existing project: Click Open Folder (Ctrl+O / Cmd+O) and select any Flutter or React Native directory.
  • New project from AI prompt: Ask the AI Agent in an empty workspace to scaffold a new Flutter or Expo/React Native app — Atomvs automatically detects the platform and boots the live phone-frame preview.

2. Flutter & React Native Setup

Atomvs supports both Flutter (pubspec.yaml) and React Native / Expo (package.json) out of the box.

  • Flutter SDK Path: If flutter is not on your system PATH, set the Flutter SDK directory in Settings → SDK Paths. Atomvs automatically injects it into integrated terminals and analyzer runs.
  • Live Phone-Frame Preview: When a project opens, Atomvs starts the web/preview server, renders it inside a selectable device frame (iPhone 15, Pixel 8, Galaxy S24), and triggers hot-reload automatically whenever you or the AI Agent save a file.
  • Physical & Emulator Devices: Use the top Device Selector to deploy directly to connected Android/iOS devices via flutter run -d <deviceId> or react-native run-android.

3. AI Agent, Chat & Autonomous Verification

The right-hand AI panel provides a platform-aware coding agent with full workspace tools:

  • Read, Search & Patch: The agent inspects your file tree, searches symbols, applies atomic multi-file edits, and displays unified diffs.
  • Autonomous Error Recovery: After modifying files, the agent runs static analysis (flutter analyze or TypeScript check) and automatically fixes compiler diagnostics before finishing its turn.
  • Slash Commands: Type / in the chat box to invoke quick actions such as fixing current diagnostics, explaining the active file, or summarizing Git changes.

4. Ghost-Text Tab Completions & Ctrl+K Inline Edits

  • Tab Completions: Pause typing in the Monaco editor to receive low-latency ghost-text completions tailored to Dart, TypeScript, and JSX. Press Tab to accept or Esc to dismiss.
  • Inline Edit (Ctrl+K / Cmd+K): Select any block of code in the editor and press Ctrl+K to open the inline instruction bar. Describe your refactor (e.g., "Convert StatelessWidget to StatefulWidget with loading state") and preview the diff inline.

5. @Mentions & Project Rules (.synkro/rules.md)

Give the AI Agent explicit architectural guardrails and context:

  • @file Mentions: Type @ in the chat input to attach specific files or folders to your prompt.
  • .synkro/rules.md: Create a .synkro/rules.md (or CLAUDE.md) file in your project root to define state-management conventions (e.g., Riverpod, Bloc, Zustand), folder structure, and design tokens. Atomvs automatically injects these rules into every agent turn.

6. Claude Code IDE Bridge

Atomvs includes a built-in WebSocket/SSE IDE server compatible with the claude CLI. Any terminal opened inside Atomvs automatically exports CLAUDE_CODE_SSE_PORT and ENABLE_IDE_INTEGRATION=true so running claude in the integrated terminal connects directly to your open editor tabs and selection.

7. Sandboxed Cloud Build (APK / AAB)

Compile signed Android packages without installing Android Studio or Gradle locally:

  1. Open the Cloud Build panel in the sidebar.
  2. Select your framework (flutter or react-native) and target (apk or aab).
  3. Click Start Cloud Build. Atomvs zips your project, validates the archive, runs the build inside an isolated Docker container, streams live logs over SSE, and provides a one-click download link when complete.

9. Plans & Usage Quotas

Atomvs enforces transparent weekly AI model pools (`usage-limits.ts`):

  • Free Plan ($0/mo): $0.50/week model pool (resets Mondays 00:00 UTC), 2,000 Tab completions/month, Auto model routing, 10 chat req/min.
  • Pro Plan ($20/mo): $5.00/week model pool, unlimited Tab completions, manual model selection, graceful fallback to Auto when the weekly pool is exhausted, 40 chat req/min.

View your live usage meters anytime at /account or inside Settings → Account in the desktop app.
