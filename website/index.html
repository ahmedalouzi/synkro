How it works

Three golden paths

The workflows Atomvs was designed around.

01

Open app → see it running

Open any Flutter or React Native project. Atomvs detects the platform, runs pub get or npm install, starts the dev server, and shows your app in the phone frame — in under 60 seconds.

02

Prompt → diff → preview

Type "Add a settings screen with dark mode toggle". The agent reads your project, writes the code, shows a unified diff, and updates the live preview automatically.

03

Error → fix → green analyze

Build fails? The error appears in the panel with a file link. Click "Fix this" — the agent patches the file, runs flutter analyze, and confirms it's clean.
