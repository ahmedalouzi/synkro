Privacy Policy

Effective Date: October 28, 2026 • Last Updated: October 28, 2026

Atomvs ("we", "our", or "us") builds a local-first AI desktop IDE for Flutter and React Native developers. This Privacy Policy explains precisely what data stays on your computer, what data is transmitted when you use cloud features, and how you can control or delete your information.

1. Local-First Workspace & Source Code Storage

By default, your project files, Git repositories, local SQLite settings database, and build outputs remain on your local machine:

  • Atomvs does not continuously upload or index your entire hard drive to our servers.
  • When you edit files, run local previews, or use the built-in Git UI and terminal, operations execute directly on your device.

2. Account & Billing Data We Collect

When you create an Atomvs account or subscribe to Atomvs Pro, we store:

  • Account credentials: Your email address, salted password hash, and rotating session/refresh tokens.
  • Subscription & usage records: Your current plan tier (free or pro), payment provider customer/subscription identifiers (via Lemon Squeezy or Stripe), and token/cost accounting in our PostgreSQL ledger to enforce weekly plan pools. Payment card numbers are processed directly by our Merchant of Record and never touch Atomvs servers.
  • Cloud-synced chat threads: If you are signed in, conversation threads and run metadata saved via /v1/threads are stored in your account so you can resume threads across sessions.

3. AI Prompts, Code Context & Third-Party Model Providers

When you trigger an AI feature (Agent chat, inline Ctrl+K edits, or ghost-text Tab completions):

  • Atomvs sends the relevant prompt, selected code snippets, open file context, and project rules (.synkro/rules.md) to the Atomvs AI Gateway (or directly to your configured provider in local development).
  • Our gateway forwards the request to the selected upstream LLM provider — Google Gemini, OpenAI, or Anthropic — using zero-data-retention API configurations where available so your code is not used to train foundation models.

4. Cloud Build Source Uploads & Automatic Temp Cleanup

When you explicitly trigger a Cloud Build to compile an Android APK/AAB:

  • The desktop app archives your project workspace (excluding node_modules, .git, and local build folders) into a ZIP archive and uploads it over HTTPS to /api/build/upload.
  • Our server validates the archive for safety, extracts it into an isolated ephemeral directory (/tmp/builds/<jobId>_extracted), and runs the build inside a network-restricted, non-root Docker container.
  • Immediate Cleanup: In a mandatory finally block immediately after the build succeeds, fails, or is cancelled, the uploaded source ZIP, the extracted source directory, and temporary local build files are permanently deleted from the build server disk. Compiled APK artifacts are stored in private object storage solely for your authenticated download.

5. Opt-In Telemetry & Crash Reporting (Sentry)

Telemetry and crash reporting in Atomvs are strictly opt-in:

  • Sentry crash reporting is disabled unless you explicitly enable telemetry in Settings.
  • Before any crash report or breadcrumb leaves your device or server, our automated scrubber (sentry-scrubber) redacts Bearer tokens, session_token cookies, Google (AIza…), OpenAI (sk-…), and Anthropic (sk-ant-…) API keys, and strips local Windows/macOS/Linux user file paths.

6. Data Retention, Access & Deletion

You may sign out, delete saved chat threads from the IDE at any time, or request complete deletion of your Atomvs account and all associated database records by emailing privacy@atomvs.com. Verified account deletion requests are completed within 14 days.

7. Contact Us

For privacy questions, data export requests, or security disclosures, contact us at privacy@atomvs.com.
