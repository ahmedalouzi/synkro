Download & Installation FAQ

Does Synkro require administrative privileges to install?

No. Synkro is packaged as an NSIS per-user installer that deploys safely into your user app data directory (%LOCALAPPDATA%\Programs\Synkro). You do not need administrative or UAC access.

How do software updates work?

Synkro features a built-in auto-updater. When a new version is released, the IDE detects it quietly in the background and displays a non-intrusive update prompt in the bottom status bar.

Is my source code uploaded anywhere when I install or use Synkro?

No. Synkro is strictly local-first. Your code stays on your physical drive and all edits, Git operations, and terminal processes execute locally. Telemetry is 100% opt-in (disabled by default), and AI features operate with zero-data-retention commercial guarantees.
