# Atomvs v0.1.3

## English

**What's new**
- **Every app gets its own identity.** The agent creates a brand for each new app: colors with readable contrast, a font, a logo, a splash screen and a launch flow (splash, onboarding, sign-in). Screens read everything from the theme, so asking for "make it green" restyles the whole app. Fonts are built into Atomvs, so they work offline.
- **Generated code compiles before you see it.** Atomvs checks the code itself (flutter analyze / TypeScript) and has the agent fix errors before the preview starts. Layout errors in the running preview (for example text overflowing a row) are found and fixed automatically, once, and only when you have credits.
- **Sharper phone frames.** The preview's phones are drawn as crisp vectors, with smooth corners and a clean Dynamic Island. They are bigger by default, and you can pick Fit, 100% or 125%. The floating preview window is just as sharp.
- **Atomvs Doctor.** Settings → Doctor checks your computer for what Flutter and Expo need (Flutter, Git, Node.js, Windows Developer Mode, disk space, internet) and fixes common problems with one click.
- **Error reports, your choice.** If you allow it, Atomvs sends anonymous error reports (never your code, prompts, keys or e-mail) so we can fix problems faster. You can turn them off anytime in Settings → Privacy.

**Fixes**
- The agent no longer stops with an error after the app's brand is set.
- "Auto-Fix Build" sends one request per failure, never twice.
- A price no longer shows as code text (like `${total}`) in Flutter apps.
- Security updates for several libraries.

Windows may show "Windows protected your PC" for the installer: click **More info**, then **Run anyway**. If you already have Atomvs, it will tell you an update is available; you can also download the new installer from atomvs.com.

## العربية

**الجديد**
- **لكل تطبيق هويته الخاصة.** ينشئ الوكيل لكل تطبيق جديد هوية كاملة: ألوان بتباين مقروء، وخط، وشعار، وشاشة افتتاحية، ومسار بداية (شاشة افتتاحية، تعريف، تسجيل دخول). تقرأ الشاشات كل شيء من الثيم، فطلب مثل «اجعله أخضر» يغيّر التطبيق كله. الخطوط مضمّنة في Atomvs وتعمل دون إنترنت.
- **الكود يُفحص قبل أن تراه.** يفحص Atomvs الكود بنفسه (flutter analyze / TypeScript) ويجعل الوكيل يصلح الأخطاء قبل بدء المعاينة. وأخطاء التصميم في المعاينة (مثل نص يتجاوز السطر) تُكتشف وتُصلح تلقائيًا، مرة واحدة، وفقط عندما يكون لديك رصيد.
- **إطارات هواتف أوضح.** تُرسم الهواتف في المعاينة كرسوم متجهية واضحة، بزوايا ناعمة وDynamic Island نظيفة. صارت أكبر افتراضيًا، ويمكنك اختيار ملاءمة أو 100% أو 125%. ونافذة المعاينة العائمة بنفس الوضوح.
- **طبيب Atomvs.** الإعدادات ← الطبيب يفحص جهازك بحثًا عمّا يحتاجه Flutter وExpo (Flutter وGit وNode.js ووضع المطوّر في Windows والمساحة والإنترنت) ويصلح المشاكل الشائعة بنقرة.
- **تقارير الأخطاء باختيارك.** إذا سمحت، يرسل Atomvs تقارير أخطاء مجهولة (لا تتضمن أبدًا الكود أو الطلبات أو المفاتيح أو البريد) لنصلح المشاكل أسرع. يمكنك إيقافها في أي وقت من الإعدادات ← الخصوصية.

**إصلاحات**
- لم يعد الوكيل يتوقف بخطأ بعد تعيين هوية التطبيق.
- «Auto-Fix Build» يرسل طلبًا واحدًا لكل فشل، وليس مرتين.
- لم يعد السعر يظهر كنص كود (مثل `${total}`) في تطبيقات Flutter.
- تحديثات أمنية لعدة مكتبات.

قد يعرض ويندوز رسالة "Windows protected your PC" عند تشغيل المثبّت: اضغط **More info** ثم **Run anyway**. إذا كان Atomvs مثبّتًا لديك فسيُعلمك بوجود تحديث، ويمكنك أيضًا تنزيل المثبّت الجديد من atomvs.com.
